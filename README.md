# Shin routine M3.3.19 — Gói tải lên GitHub

Gói đã rút gọn còn **79 tệp**, gồm toàn bộ ứng dụng, ảnh, font, giọng Việt offline và các giấy phép cần giữ.

## Tải lên

1. Giải nén gói ZIP.
2. Mở thư mục Shin-routine-M3.3.19-GitHub.
3. Tải toàn bộ nội dung **bên trong** thư mục lên đúng vị trí có index.html trên GitHub. Giữ nguyên cấu trúc assets.
4. Không tải nguyên tệp ZIP lên để thay cho ứng dụng.
5. Giữ cùng địa chỉ web để tiếp tục dùng dữ liệu học viên trên thiết bị đó. Khi app báo bản mới, chọn cập nhật.

Giao diện, nội dung, cách tính tiến độ và dữ liệu của M3.3.19 không thay đổi. Đã bỏ các ghi chú phiên bản cũ, hướng dẫn cũ, tệp mở xem thử trên máy và bộ font Google Sans Flex không còn sử dụng.

Bản đầy đủ để xem thử trên máy vẫn được giữ riêng. Gói này dùng để đưa lên GitHub Pages hoặc website HTTPS.
